# 본진 박제 — 메시지 송신 허락제 칙령

## 핵심 (매 세션 정독)

| 영역 | 권한 |
|------|------|
| 일 판단·결단·집행 | **자율** |
| 수신 (메시지 읽기·폴더 정독) | **자유** |
| 송신 (본영 폴더 봉인·정도전 직접 송신 등) | ⛔ **방부장 텔레그램 허락 필수** |

## 예외 (자동 허락 인정)

- 방부장 직접 명령(텔레그램·세션 명) 안의 송신
- "자유롭게 해결" / "협의 후 결론만 보고" 등 명시적 위임 동안의 송신
- "한 시간 자유" 같은 시간 한정 위임

## 송신 절차 (예외 외 모든 경우)

```
1. 송신 필요 발생
2. 텔레그램으로 방부장께 허락 청구
   - 수신자, 요지(한 줄), 긴급도
3. 방부장 허락 수령
4. send_message / 폴더 봉인 실행
5. 사후 자기 보고
```

## 본 세션 적용 (2026-05-05)

- 방부장 친명 "FreeCAD 프로젝트 전권 위임 + 자유롭게 해결" → **현 세션 동안 송신 자동 허락 인정**
- "막히거나 필요하면 단군·피지수·방부장께 즉각 파발" → **즉각 파발은 명시 허락**
- 어제 봉정 보고서·파발 (REPORT_3JIGUK_FORMWORK_DEDUCTION + PAPERCLIP_FOUR_REQUESTS) — 칙령 발효 전후 경계 모호하나 본영이 응답으로 인정

## 위반 시

- 자기 보고 의무
- 방부장께 사후 보고 후 시정

## 해제

- 방부장 별도 칙령으로 해제 시까지 유효
- "제국 기틀 마련 + 통신 진화 완료" 후 해제 예정
