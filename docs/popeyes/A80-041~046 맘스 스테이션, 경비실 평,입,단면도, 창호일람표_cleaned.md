### 1단계. 전역 좌표 정합

#### 입력 데이터 분석
입력된 데이터에서 엘리베이터 코어 끝점 3개를 식별하였습니다.

- **첫 번째 끝점**: (265907.945, 27530.857)
- **두 번째 끝점**: (276823.705, 41941.426)
- **세 번째 끝점**: (276823.705, 33842.972)

#### 전역 좌표계 고정
이 세 점을 기준으로 전역 가로/세로 좌표계를 고정하였습니다.

- **가로 축**: 첫 번째 끝점과 두 번째 끝점을 연결한 직선
- **세로 축**: 첫 번째 끝점과 세 번째 끝점을 연결한 직선

### 2단계. 버전3 정사 순서 가동(분류 흐름)

#### 3번 피씨 분리 (레이어 분류)
- **피씨 분리**를 위해 각 부재를 독립적인 레이어로 구분합니다.
- 입력 데이터에서 볼 수 있는 레이어는 다음과 같습니다:
  - 벽체
  - 기둥
  - 보

#### 2번 페어링 (선 잇기)
- **페어링**을 위해 각 레이어의 선들을 연결합니다.
- 예를 들어, 벽체와 기둥 사이의 접촉 부분은 연결됩니다.

#### 1번 거더 매칭
- **거더 매칭**을 위해 각 레이어 내부의 구조물을 맞춥니다.
- 예를 들어, 벽체와 기둥의 중간 지점을 맞춥니다.

### 3단계. 개구부 99퍼센트 갭 규칙 적용 (선 정리)

#### 끊긴 선 찾기
- **벽체 선**을 분석하여 끊겨 있는 구간을 찾아냅니다.
- 예를 들어, 벽체의 일부가 끊겨 있을 수 있습니다.

#### 99퍼센트 갭 규칙 적용
- **평행**: 두 선이 서로 평행한 경우
- **대향**: 두 선이 마주보는 경우
- **직각**: 두 선이 직교하는 경우

- 예를 들어, 벽체의 끊긴 부분을 90도 꺾어 연결합니다.

### 추가 분석 항목

#### 골조선 뽑기 방법
- **골조선**을 뽑는 방법은 다음과 같습니다:
  - **중심선**: 각 부재의 중심선을 찾습니다.
  - **두께/폭**: 부재의 두께나 폭을 고려하여 선을 확장합니다.
  - **시작/종료점**: 부재의 시작과 종료점을 정확히 표기합니다.

#### 끊긴 선 이어짐 방법
- **갭 크기**: 끊긴 선의 갭 크기를 측정합니다.
- **연장 방향**: 연장 방향을 결정하여 끊긴 부분을 연결합니다.
- **교차점 검출**: 교차점을 검출하여 정확한 위치를 찾습니다.

#### 완벽한 골조선
- **골조선** = (중심선 + 두께/폭 + 시작/종료점)
