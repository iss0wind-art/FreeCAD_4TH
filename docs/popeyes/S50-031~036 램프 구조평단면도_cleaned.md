### 1단계. 전역 좌표 정합

#### 입력 데이터 분석
입력된 데이터에서 엘리베이터 코어 끝점 3개와 4번째 검증용 끝점을 식별하였습니다.

- **엘리베이터 코어 끝점 1**: (x: -200, y: 50)
- **엘리베이터 코어 끝점 2**: (x: 300, y: 50)
- **엘리베이터 코어 끝점 3**: (x: 100, y: 150)

#### 전역 좌표계 고정
기준점으로 엘리베이터 코어의 중앙 점을 선택하여 전역 좌표계를 고정합니다. 중앙 점은 (x: 100, y: 50)입니다.

- **중央点**: (x: 100, y: 50)

#### 검증용 끝점 위치 확인
4번째 검증용 끝점의 좌표는 (x: 200, y: 60)입니다. 이 점은 기준점과 일치하지 않으므로 [좌표_불일치] 로그를 남깁니다.

- **[좌標_不一致]**: (x: 200, y: 60)

#### 결과
| 좌표 | 상태 |
|------|------|
| (-200, 50) | 정합 |
| (100, 50)  | 기준점 |
| (300, 50)  | 정합 |
| (200, 60)  | [좌標_不一致] |

### 2단계. 버전3 정사 순서 가동(분류 흐름)

#### 1번 거더 매칭
- **정사 선**: (x: -200, y: 50) -> (x: 100, y: 50)
- **정사 선**: (x: 100, y: 50) -> (x: 300, y: 50)

#### 2번 페어링(선 잇기)
- **정사 선**: (x: -200, y: 50) -> (x: 100, y: 50) -> (x: 300, y: 50)

#### 3번 피씨 분리(레이어 분류)
- **레이어 분류**: 정사 선은 하나의 레이어로 분류합니다.

### 3단계. 개구부 99퍼센트 갭 규칙 적용(선 정리)

#### 갭 규칙 검토
- **정사 선**: (x: -200, y: 50) -> (x: 100, y: 50) -> (x: 300, y: 50)
  - 이 구간은 완전히 연결되어 있어 갭 규칙을 적용하지 않습니다.

### 4단계. 출력 형식

| 좌표 | 상태 |
|------|------|
| (-200, 50) | 정합 |
| (100, 50)  | 기준점 |
| (300, 50)  | 정합 |
| (200, 60)  | [좌標_不一致] |

#### 추론 로그
- **[좌標_不一致]**: (x: 200, y: 60)
  - 이 좌표는 기준점과 일치하지 않으므로 즉시 검수자의 확인이 필요합니다.

### 추가 분석 항목

#### 골조선 뽑기
- **골조선**: 정사 선을 중심선으로 추정합니다. (x: -200, y: 50) -> (x: 300, y: 50)

#### 끊긴 선 이어짐 방법
- **간격**: 100mm
- **연장 방향**: 정사 선의 방향을 유지하여 연장합니다.
- **교차점 검출**: 기준선(수평/수垂直)과 교차점을 찾아 연결합니다.

#### 완벽한 골조선
- **골조선**: (x: -200, y: 50) -> (x: 300, y: 50)
  - 중심선 + 두께(100mm) + 시작/종료점

#### 기준선 교차점 좌표
- **수平线**: (x: -200, y: 50), (x: 300, y: 50)
- **水垂直线**: (x: 100, y: 50)

#### 개구부 위치와 크기
- **出入口**: 없음
- **窗框**: 없음
- **皮特**: 없음

#### 단차 구간
- **层内高度差**: 없음

#### 부재 카탈로그
| 종류 | 기호 | 단면 | 수량 | 위치 | 층 |
|------|------|------|------|------|----|
| 벽체 | W | 100x200 | 3 | (x: -200, y: 50) -> (x: 300, y: 50) | 1 |

#### 신뢰도
- **확실**: 정사 선과 끊김 구간 확인 완료
