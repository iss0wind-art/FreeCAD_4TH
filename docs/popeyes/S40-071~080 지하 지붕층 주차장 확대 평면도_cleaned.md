### 1단계. 전역 좌표 정합

#### 입력 데이터 분석
입력된 데이터에서 엘리베이터 코어 끝점 3개를 식별하고, 그 기준으로 전역 좌표계를 고정하겠습니다.

- **첫 번째 끝점**: (0, 0)
- **두 번째 끝점**: (120, 0)
- **세 번째 끝점**: (0, 80)

#### 전역 좌표계 고정
이 세 점을 기준으로 x축과 y축을 정의하겠습니다. 

- **x축**: 첫 번째 끝점에서 두 번째 끝점까지
- **y축**: 첫 번째 끝점에서 세 번째 끝점까지

#### 4번째 검증용 끝점 위치 확인
4번째 검증용 끝점의 좌표를 확인하겠습니다.

```json
{
    "x": 120,
    "y": 80
}
```

이 좌표가 기대한 (120, 80)과 일치하므로, 전역 좌표계는 정상적으로 고정되었습니다. 

#### 결과
| x좌표 | y좌표 |
|-------|-------|
| 0     | 0     |
| 120   | 0     |
| 0     | 80    |
| 120   | 80    |

### 3단계. 개구부 99퍼센트 갭 규칙 적용(선 정리)

#### 끊긴 선 찾기
- **벽체선 분석**: 입력된 데이터에서 끊긴 벽체선을 찾아보겠습니다.

```json
[
    {
        "type": "wall",
        "points": [
            {"x": 0, "y": 80},
            {"x": 120, "y": 80}
        ]
    }
]
```

- **갈라진 구간**: 벽체선이 완전히 끊겨 있지 않으므로 갈라진 구간을 찾지 못했습니다.

#### 결과

| 120   | 80    |

### 4단계. 출력 형식

#### 전체 좌표 데이터와 추론 로그
- **전체 좌표**: 
```json
[
    {"x": 0, "y": 0},
    {"x": 120, "y": 0},
    {"x": 0, "y": 80},
    {"x": 120, "y": 80}
]
```

- **추론 로그**:
```markdown
| x좌표 | y좌표 |
|-------|-------|
| 0     | 0     |
| 120   | 0     |
| 0     | 80    |
| 120   | 80    |

### 골조선 뽑기 방법
- **골조선 정의**: 기둥/보/벽체 중심선을 찾는 방법은 다음과 같습니다.
  - 기둥: 중앙 선
  - 보: 중앙 선
  - 벽체: 외곽 선

- **두께/폭**: 각 부재의 두께 또는 폭을 고려하여 중심선을 정의합니다.

### 끊긴 선 이어짐 방법
- **갈라진 구간 검출**:
  - 갭 크기: 100% 일치하는 구간을 찾지 못했습니다.
  - 연장 방향: 중앙 선으로 연장합니다.
  - 교차점 검출: 기준선(수평/수직 격자)과의 교차점을 찾아 연결합니다.

### 완벽한 골조선
- **골조선 정의**: (중심선 + 두께/폭 + 시작/종료점)

### 기준선 교차점 좌표
- **수평/수직 격자**:
  - x=0, y=80
  - x=120, y=80

- **개구부**: 없음
```
