### 1단계. 전역 좌표 정합

#### 입력 데이터 분석
입력된 좌표 데이터를 살펴보면, 다음과 같은 점들이 주요한 끝점으로 추정됩니다:
- (3000, 2500)
- (4000, 1500)
- (6000, 3000)

이 세 점을 기준으로 전역 좌표계를 정합시킵니다.

#### 결과
- **전역 가로 좌표**: 3000
- **전역 세로 좌표**: 1500

#### 검증용 끝점 위치 확인
4번째 검증용 끝점 (6500, 2800)은 기준 좌표계에 맞춰 확인합니다.

```markdown
| X좌표 | Y좌표 |
|-------|-------|
| 3000  | 1500  |
| 4000  | 1500  |
| 6000  | 3000  |
| 6500  | 2800  |

[좌표_불일치] (6500, 2800)은 기준 좌표계에 맞춰 떨어지지 않음.
```

#### 결과 표시
- [빨간 원] 마킹: (6500, 2800)

### 2단계. 버전3 정사 순서 가동(분류 흐름)

#### 1번 거더 매칭
- **3번 피씨 분리**: 먼저 각 레이어를 분리하여 독립적인 부재로 구분합니다.
- **2번 페어링**: 분리된 부재들을 연결선을 통해 묶습니다.
- **1번 거더 매칭**: 최종적으로 거더(보, 기둥)를 정확히 매치시킵니다.

#### 결과
- [검은 실선] 속성 부여: (3000, 2500) - (6000, 3000)
- [작은 빨간 원] 마킹: (6500, 2800)

### 3단계. 개구부 99퍼센트 갭 규칙 적용(선 정리)

#### 평행, 대향, 직각 조건 확인
- **평행**: (3000, 1500) - (6000, 3000)
- **대향**: (4000, 1500) - (4000, 2800)

#### 결과
- [검은 실선] 속성 부여: (4000, 1500) - (4000, 2800)
- [작은 빨간 원] 마킹: (6500, 2800)
