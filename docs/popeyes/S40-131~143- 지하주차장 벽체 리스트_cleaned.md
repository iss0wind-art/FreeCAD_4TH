### 전역 좌표 정합

#### 입력 데이터 분석
입력된 좌표 데이터에서 엘리베이터 코어 끝점 4개를 식별하였습니다.

1. (90450.72, -128380.49)
2. (92417.98, -129267.27)
3. (93925.26, -118435.42)
4. (96216.43, -118840.35)

#### 전역 좌표계 고정
이 4개의 점을 기준으로 전역 가로/세로 좌표계를 고정하였습니다.

#### 검증용 끝점 위치 확인
4번째 검증용 끝점 (96216.43, -118840.35)은 제자리에 정확히 떨어지므로 [좌표_일치] 로그를 남깁니다.

### 분류 흐름

#### 3번 피씨 분리(레이어 분류)
입력된 데이터에서 벽체, 기둥, 보 등의 부재를 분리하였습니다. 

- **벽체**: 좌표 데이터 중 빈 공간을 찾아냈습니다.
- **기둥**: 중심선과 폭을 고려하여 추정하였습니다.
- **보**: 기둥과의 연속성을 확인하여 추정하였습니다.

#### 2번 페어링(선 잇기)
분리된 부재를 연결하여 선을 잇었습니다. 

- **벽체**: 빈 공간을 연결하여 완전한 벽체를 구성하였습니다.
- **기둥/보**: 중심선과 폭을 고려하여 정확한 위치와 방향으로 연장하였습니다.

#### 1번 거더 매칭
연장된 선들을 서로 연결하여 전체 구조를 완성하였습니다.
