# 방부장 도면판독·모델링 교본 (2026-07-02)

> 원 도면 자체의 노이즈(끊어진 선, z값 불일치, 대충 그린 선)가 1차 문제.
> 그래서 **초기 CAD 정리가 파싱의 절반**이다.

## 1. 도면 수령 시 순서

1. **배치도 훑기**: 총 동수, 필로티 위치, 동별 층수, 주차장·내부시설 구성,
   썬큰·주통로·보조통로 — 머릿속에 개략 지도 형성.
2. **기초부터**: 최하층(지하주차장 바닥)이 시공 시작점이므로 기초 도면 먼저.

## 2. 색상 코드 (관례) — 이천 실측 대조

| 색 | 의미 (방부장) | 101동 S30 실측 |
|---|---|---|
| **노랑** | 해당층 골조선 — 바닥+1.2m 수평절단선 | XR{동층}평면도(구조) 블록 내 실존 (기준층 657선!) |
| **초록** | 기초선 (기초 도면에서) | XR지하N층평면도 A-WALL-B 등 |
| **파랑/보라** | 하부벽체·하부기둥 별도 레이어 | S-하부벽체=파랑 ✓, S-GIRDER=보라 ✓, S-BEAM=하늘 |
| 빨강 | 개구부/중심선 등 | S-OPEN=빨강 ✓ |

## 3. 층 귀속 관례 (핵심 중의 핵심)

- **보·슬라브 = 상부층 도면 소속**: 지하2층 상부 보는 지하1층 도면에,
  지하1층 보는 1층(또는 지붕층) 도면에 그려진다.
- **기둥·벽 = 해당층 도면에 해당층 골조(노란 골조선)** + 추가로
  파랑/보라 "하부벽체·하부기둥" 레이어가 별도 표기됨.
  → 층 전환 시 벽두께 변화·기둥 축소·단절이 한눈에 보임.
- 지하2층 도면 = 기초 도면.

## 4. 기초 읽기

- 골조 입장에선 **초록 기초선만 분리**하면 됨 (줄기초/방석/온통 무관).
- 기초 두께는 부호별로 도면에 표기 — 지하2층 바닥레벨에서 **아래로** 적용.
- **E/V PIT는 기초와 동시(오히려 선)시공** — 기초 파싱 때 함께 고려.

## 5. 창·문 구간 처리 (방부장 방식)

- 노란 골조선은 +1.2m 절단이므로 창 형태에 따라 골조선이 달라짐/끊어짐.
- **벽체로 전부 형성 → 창 위치만 기억 → 창 크기만큼 나중에 공제.**
  (아니면 역보·인방보를 추가로 그려야 해서 더 번거로움)
- 이천 구현: bridge_collinear로 창 구간 브리징. 기준층 실험 —
  브리지 gap 900/1500/2600mm → 폐합 76→201→203㎡ (방향 검증됨).

## 6. 작업 순서 (방부장 개발 방식 — 수평부재 우선)

1. 골조선 분리 보관 (수직부재용 대비)
2. **보선만 따로 분리 → 보부터 그림** (수직 먼저 그리면 높이값이 수시로
   바뀌어 비효율 — 그래서 수평 우선을 개발함)
3. 구간별 높이값은 미리 상기(별도 저장)
4. 수직부재는 골조선 따라 올리다 **수평부재와 만나는 곳에서 멈춤** = 완성
5. 오픈구(수직·수평)만 잘 구분
6. 계단·램프는 코어상세도·램프상세도 별도 참조
7. 기준층은 변수가 줄어 더 쉬움

## 7. 초기 CAD 정리 표준 (자동 전처리 목표)

- 끊어진 선 연결
- 골조선 분리 (색상/레이어 기준)
- 높이값 기입 또는 별도 저장
- 부재별 별도 보관 — 실전은 **CJ(시공줄눈) 분리**까지 (차후 적용 예정)
- **z값 0으로 평탄화** — 수직방향 끊어짐 제거

## 8. 이천의 오늘 발견 (교본 적용 결과)

1. **XR{동층}평면도(구조) 블록** — S-* 블록만 뒤지느라 놓쳤던 노란 골조선의
   실제 위치. **기준층 골조선 657선 존재 확인** → S20 없이도 기준층 벽 가능.
2. B2F의 S-B1F-101-BASE 블록 = 벽체 블록 사본(7010개 동일) —
   기초 아님. 진짜 기초선은 XR지하 도면의 초록선. [INFER 0.75 해석 정정 필요]
3. 색상 신호를 전혀 안 쓰고 있었음 — 파서에 resolved color 축 추가 필요.



## 9. 방부장 답변 4건 (2026-07-02 2차 문답)

1. **지상층 초록선**: 101동 구조평면도 상단 3개 도면은 동기초(초록=골조 관련).
   그 외 지상·지하 평면의 초록(십자 등)은 **철근 배근 지시 — 골조 무관, 제외**.
2. **S30-571 지하외벽 리스트**: 노랑=골조선(단면) 속 초록=철근 형상.
   좌측 초록 단선 = "잘라서 보여준다"는 절단 표기일 뿐.
   → **벽두께는 노란 단면선에서 추출 가능.**
3. **CJ(시공줄눈)**: 한번에 타설 불가 → 구간 분할. 악세스로드·우선동·공기
   최적화로 결정, **정해진 규칙 없고 시공 중에도 수없이 변경**.
   → 데이터 구조: CJ를 부재 속성에 종속시키지 말고, 부재 위에 얹는
   **가변 구간 태깅 레이어**로 설계할 것.
4. **CAD 정리 완료 판정**: 방대한 도면이라 완료 후에도 안 되는 곳이 존재.
   안 되는 곳은 표시해두고 CJ별로 모아 상황에 따라 수정보완.
   → 완료 기준 = "결함 0"이 아니라 **"결함이 표시되어 관리되는 상태"**.
   (이천의 붉은표시 방식과 일치 — 방향 확증)
