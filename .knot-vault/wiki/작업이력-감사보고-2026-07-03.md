## 이번(07-03) 시공 — "오픈 먼저, 채움은 도면으로"

1. **face-우선 오픈**: X마크/계단 = 지시자, 실경계 = 중심 포함 폐합 face(벽 내측면).
   face 실패 시 bbox 폴백 + [미확정] 플래그 (기준층: face 3 / 폴백 8).
   절삭 증가: 1F 36.4→43.5㎡, 기준층 31.5→41.6㎡ (계단실 실면적 반영).
2. **미검증 트레드 전량 제거** — 계단실은 정확히 오픈만. 채움은 실측 매핑 후.
3. **코아#1 계단 실측 확보** (A40-301): UP런 서측열 +Y 8단(y피치 270 실측),
   DN런 동측열 -Y, 단번호 1~18, (270X8EA), E.V홀 남측, 15인승 ELEV 동측.
4. **코어 3개 확인** — 코아#1/#2/#3 각각 전층 평면 + 계단·EV 단면 존재.
   검출된 계단클러스터 2개 → 1개 누락 추적 필요.
   코아#1=옥탑지붕 / 코아#3=옥탑 평면 존재 → **층변화(15/16층) 단서**.

## 남은 작업 (방부장 지시 반영 순서)

1. 계단 1개소 누락 추적 + 코어별(1~3) S30 매핑 → 실측 형상 채움
2. EV bbox 폴백 8건 → 샤프트 벽 폐합 보정으로 face 승격
3. 기준층 창 오픈 — 창구간 브리지(=창 위치 실측) 구간 벽 공제,
   규격은 A50 창호일람표 대조
4. 옥탑·층변화 — 코어 옥탑 평면 + S30 옥상 시트 파싱
