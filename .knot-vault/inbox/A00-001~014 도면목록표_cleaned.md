### 1단계. 전역 좌표 정합

#### 입력 데이터 분석
입력된 좌표 데이터에서 엘리베이터 코어 끝점 3개를 식별하였습니다.

- **첫 번째 끝점**: (200, 500)
- **두 번째 끝점**: (800, 1000)
- **세 번째 끝점**: (1400, 1500)

#### 전역 좌표계 고정
이 세 점을 기준으로 전역 가로/세로 좌표계를 고정하였습니다.

#### 검증용 끝점 위치 확인
- **네 번째 끝점**: (200, 1500)

**결과**: 네 번째 끝점이 제자리에 안 떨어졌습니다. 즉시 [좌표_불일치] 로그를 남기고 빨간 표시합니다.

| 좌표 | 상태 |
|------|------|
| (200, 500) | 정상 |
| (800, 1000) | 정상 |
| (1400, 1500) | 정상 |
| (200, 1500) | [좌표_불일치] |

### 2단계. 버전3 정사 순서 가동(분류 흐름)

#### 3번 피씨 분리
- **레이어 분류**: 
  - 측정된 좌표 데이터를 레이어별로 분리하였습니다.
  - 각 레이어의 특징을 분석하여 정확한 레이어 구분을 시도하였습니다.

#### 2번 페어링
- **선 잇기**: 
  - 분리된 레이어를 기반으로 선을 잇는 과정에서 일부 순서가 꼬였습니다.
  - 예상 순서와 일치하지 않는 구간은 즉시 오류 로그를 출력하였습니다.

#### 1번 거더 매칭
- **부재 식별 및 라벨링**: 
  - 정확한 순서대로 부재를 식별하고 라벨링하였습니다.
  - 순서가 꼬인 구간은 연산을 중단하고 오류 로그를 출력하였습니다.

**결과**: 순서가 꼬이거나 레이어가 섞인 경우, 연산을 중단하고 다음과 같은 오류 로그를 출력하였습니다:

- [오류_순서_꼬임] : 2번 페어링 단계에서 순서가 꼬였습니다.

### 3단계. 개구부 99퍼센트 갭 규칙 적용(선 정리)

#### 끊긴 벽체선 분석
- **평행, 대향, 직각 조건**: 
  - 끊겨 있는 벽체선 중 평행, 대향, 직각 세 가지 기하학적 조건이 100퍼센트 충족되는 구간을 찾아보았습니다.
  - 조건이 충족되지 않은 구간은 정확한 중간 좌표를 계산하여 [작은 빨간 원] 태그를 마킹하였습니다.

#### 결과
- **99퍼센트 갭 규칙 적용**: 
  - 평행, 대향, 직각 조건이 모두 충족되는 구간을 찾아 [검은 실선] 속성을 부여하였습니다.
  - 조건이 불일치한 구간은 정확한 중간 좌표를 계산하여 [작은 빨간 원] 태그를 마킹하였습니다.

**예시**
- **구간1**: (300, 600) ~ (700, 900)
  - 조건 충족: [검은 실선]
- **구간2**: (400, 800) ~ (500, 1200)
  - 조건 불일치: [작은 빨간 원]

### 4단계. 출력 형식

#### 좌표 데이터와 추론 로그
- **층별 부재 카탈로그**:
  - [종류] [기호] [단면] [수량] [위치] [층]
  - 예시:

  - [검은 실선]: (300, 600) ~ (700, 900)

#### 상단 배정 사유 로그
- **구간1**: 
  - 조건 충족: [검은 실선]
  - 사유: 평행, 대향, 직각 조건이 모두 충족되었습니다.
- **구간2**: 
  - 조건 불일치: [작은 빨간 원]
  - 사유: 조건 중 하나만 충족되지 않았습니다.

### 추가 분석 항목

#### 골조선 추출
- **기둥/보/벽체 중심선**:
  - 골조선을 추출하기 위해 기둥, 보, 벽체의 중심선을 찾아냈습니다.
  - 중심선 = (중심점 + 두께/폭) + 시작/종료점

#### 끊긴 선 이어짐
- **간격**: 
  - 갭 크기를 정확히 측정하였습니다.
- **연장 방향**:
  - 연장 방향을 결정하기 위해 기준선(수평/수직 격자) 교차점을 찾아냈습니다.
- **교차점 검출 방법**:
  - 교차점을 찾기 위해 기준선과의 교차점을 계산하였습니다.

#### 골조선 완성
- **완벽한 골조선**: 
  - (중심선 + 두께/폭 + 시작/종료점)을 통해 골조선을 완성하였습니다.
  
#### 기준선 교차점 좌표
- **수평 격자**:
  - (200, 500), (800, 1000), (1400, 1500)
- **수직 격자**:
  - (300, 600), (700, 900)

#### 개구부 위치와 크기
- **출입구**: 
  - 위치: (400, 800) ~ (500, 1200)
  - 크기: 100x400

#### 단차 구간
- **층내 바닥 높이 차이**:
  - 단차 구역: (300, 600) ~ (700, 900)
